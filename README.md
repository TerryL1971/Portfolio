## ✨ Features

- ⚡ **Fast + responsive layout** using Tailwind and Vite
- 🧭 Smooth **scroll navigation** for mobile + desktop
- 🌀 **Custom animated cursor** (desktop only)
- 🎥 **3D Spline animation** on the homepage
- 📝 **Downloadable CVs** (UK & German versions)

- 🌙 **Dark mode** support
