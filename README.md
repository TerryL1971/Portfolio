## 📌 About This Portfolio

This is my **personal website and portfolio**, built to reflect both my technical training and years of real-world business acumen.

> I’m a former automotive sales & purchasing manager turned web developer and data analyst — blending modern UI design with insights from a career in client success, team leadership, and market analysis.

### ✨ Features
- ⚡ **Built with React + Vite** for ultra-fast performance
- 🎨 Styled using **Tailwind CSS 4.1**
- 🔁 Smooth page transitions with **Framer Motion**
- 🌀 3D animation powered by **Spline**
- 🎯 **Call-to-action buttons** drive visitors to connect
- 🧾 **CV downloads** in UK & German styles
- 💬 Working **Contact Form** with `mailto:`
- 📱 Fully responsive, **mobile-first** design
